RecoverTick v0.1.0

Deterministic decisions. Bounded recovery. Inspectable replay.

Rustno_stdZero dependenciesGitHub Actions CI
Project details+

A zero-dependency Rust decision engine with typed state, logical ticks, bounded retries and a fixed-capacity journal. Semantic replay verifies decisions from a known initial state. Published on GitHub and crates.io, with GitHub Actions CI.

Current scope

Decision recovery is separate from actuator I/O. Hardware recovery, durable logging, safety certification and MCU timing guarantees are not claimed.
